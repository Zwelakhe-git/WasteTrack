# WasteTrack
A web service for tracking thrown away products in fast food restaurants

требования к системе.
–	Быстрый ввод списания: выбор продукта плиткой, количество, причина — не более трёх действий.
–	Обязательный справочник причин с возможностью настройки и обязательным комментарием для «прочего».
–	Режим планшета/терминала, крупные элементы управления, работа в условиях пиковой нагрузки.
–	Справочник продуктов с себестоимостью и расчёт суммы списания.
–	Отчёты менеджера: по продуктам, причинам, времени суток и сумме; сравнение периодов.
–	Блок рекомендаций «причина → вероятная проблема процесса».
–	Роли: сотрудник (ввод), менеджер (аналитика, справочники). Экспорт в CSV
